# Client Onboarding

Implementation stages are Lead, Qualified, Discovery, Proposal, Contract signed, Tenant provisioned, Data collection, Configuration, Initial migration, User testing, Training, Final migration, Go-live, Hypercare, and Active support.

An implementation records industry, company/branch/user counts, modules, existing system, administrators, department representatives, migration scope, integrations, training, target date, risks, actions and sign-offs. Import templates and execution are deferred until Phase 2, but the implementation-project record is established in Phase 0.
