# Client Onboarding

Implementation stages are Lead, Qualified, Discovery, Proposal, Contract signed, Tenant provisioned, Data collection, Configuration, Initial migration, User testing, Training, Final migration, Go-live, Hypercare, and Active support.

An implementation records industry, company/branch/user counts, modules, existing system, administrators, department representatives, migration scope, integrations, training, target date, risks, actions and sign-offs. The implementation-project record was established in Phase 0. Phase 2 now provides controlled CSV templates, staged validation, previews, and atomic confirmation for business parties and catalogue items.

Phase 1 implements auditable stage changes from tenant provisioning through active support. Additional implementation detail fields and module-specific import targets remain deferred to their owning phases.
