# Client Onboarding

Implementation stages are Lead, Qualified, Discovery, Proposal, Contract signed, Tenant provisioned, Data collection, Configuration, Initial migration, User testing, Training, Final migration, Go-live, Hypercare, and Active support.

An implementation records industry, company/branch/user counts, modules, existing system, administrators, department representatives, migration scope, integrations, training, target date, risks, actions and sign-offs. The implementation-project record was established in Phase 0; controlled import templates and execution are the final planned Phase 2 slice.

Phase 1 implements auditable stage changes from tenant provisioning through active support. The remaining detail fields and import templates remain deferred until master data.
