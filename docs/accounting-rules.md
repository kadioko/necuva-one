# Accounting Rules

Accounting is deferred beyond Phase 0. Its future implementation must use double-entry, immutable posted journals, atomic database posting, source documents, explicit document states, reversal-based correction, auditable creator/approver information, and integer-minor-unit or documented-decimal money values.

No module may create ledger entries independently. A central posting service will document and enforce treatments for sales, receipts, purchases, payments, returns, expenses, payroll, assets, depreciation and production.

Current status: no accounting tables or posting functions have been implemented.
